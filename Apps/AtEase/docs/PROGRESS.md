## 版本演进路线

### `0.1.x` — MVP 闭环（当前）

**状态**：已可运行
**主题**：打开即可练习。
**范围**：引导页、情绪签到、推荐呼吸、4-7-8 / Box / SOS、计时器、本地进度、可选声音引导。
**完成标准**：

- [x] 无登录即可使用。
- [x] 三个呼吸模式可运行。
- [x] 计时器 1–60 分钟可运行。
- [x] 情绪与练习写入本地 SwiftData。
- [x] 进度页能表达分钟数、连续天数和热力图。
- [x] 声音引导可关闭。
- [ ] TestFlight 冒烟验证。

### `0.2` — 身体在场与系统能力

**主题**：让触觉和 iOS 系统深度达到真实产品水准。
**范围**：

- Core Haptics 与吸气 / 屏息 / 呼气节奏精确同步。
- HealthKit 正念分钟写入。
- Live Activity 显示呼吸节奏与计时进度。
- 温和提醒管理。
- 后台音频边界与耗电策略。

**完成标准**：

- [ ] 触觉阶段切换与呼吸动画偏差 ≤250ms。
- [ ] HealthKit 授权失败不阻断本地记录。
- [ ] Live Activity 在锁屏稳定显示阶段。
- [ ] 提醒文案不制造压力，无红色或警告样式。

### `0.3` — 非声音练习

**主题**：补齐差异化体验，而不是继续堆内容。
**范围**：

- 念头放下交互。
- 触摸身体扫描探索。
- 环境音混音：雨声 / 流水 / 虫鸣。
- 混音预设保存。
- 极暗模式细节打磨。

**完成标准**：

- [ ] 念头放下可完成输入、长按淡出与结束记录。
- [ ] 身体扫描可在无音频状态下完成。
- [ ] 至少 3 种免版税音景通过循环与频率处理。
- [ ] 所有新练习可在静音设备上使用。

### `0.4` — 内容基础设施

**主题**：建立播放与分发底座，为订阅做准备。
**范围**：

- 引导冥想播放器。
- 音频资产 schema：来源、授权、分轨、时长、导师、主题。
- 免费基础库接入。
- 后台下载与离线校验。
- 收藏与最近练习。

**完成标准**：

- [ ] 播放器支持暂停、15s 前后跳转、阶段标签、定时关闭。
- [ ] 音频资产有授权台账。
- [ ] 免费用户可离线使用呼吸、计时器与触觉练习。
- [ ] 内容加载失败不出现弹窗压力。

### `0.5` — 订阅闭环

**主题**：建立可持续商业模式。
**范围**：

- StoreKit 2。
- 免费 / 订阅分层。
- 7 天试用。
- 恢复购买。
- 订阅状态缓存。
- 离线下载授权。
- 收尾卡片中的低调订阅入口。

**完成标准**：

- [ ] 前 3 次练习无订阅提示。
- [ ] 订阅失败不影响已有本地数据。
- [ ] 试用结束自动降级且保留数据。
- [ ] 恢复购买在无网状态有清晰反馈。

### `1.0` — 公开发布

**主题**：完成稳定性、合规与商店交付。
**范围**：

- 无障碍审计。
- 本地化复查。
- App Store 截图与文案。
- 隐私问卷。
- TestFlight 灰度。
- 崩溃与性能回归。

**完成标准**：

- [ ] TestFlight 使用两周，无 P0/P1 缺陷。
- [ ] 冷启动感知低于 1s。
- [ ] 本地迁移无数据丢失。
- [ ] 隐私声明与实际数据使用一致。
- [ ] App Store 审核材料完整。

### `1.x` — 留存与深度

**主题**：在不制造压力的前提下提升长期价值。
**候选方向**：

- 专注模式联动。
- 控制中心 SOS 呼吸。
- 情绪趋势与正念分钟观察。
- 多周课程。
- 睡眠故事。
- 空间音频。

**约束**：只有在不破坏“零摩擦、不评判、不依赖声音”三原则时才加入。

## 近期优先级

1. 打通 Core Haptics 与呼吸节奏。
2. 实现 HealthKit 正念分钟写入。
3. 完成“念头放下”交互原型。
4. 定义内容分发与订阅分层 API。
