# At Ease（心安）设计文档

> 版本 v2.0 设计基线 ｜ 当前实现 v0.4.0 内容基础设施 ｜ 目标平台 iOS 17.0+

## 1. 产品定义

### 1.1 一句话定位

At Ease（心安）是一款让“打开 App”这件事本身不构成压力的冥想应用。免费呼吸与计时器承担日常习惯，后续订阅解锁深度睡眠故事与结构化课程。

### 1.2 核心设计原则

| 原则 | 含义 | 落地表现 |
|---|---|---|
| 零摩擦启动 | 无需注册即可使用计时器与呼吸 | 首屏可直接进入呼吸，无登录墙 |
| 情绪优先于内容 | 以当下情绪为入口，而不是让用户搜索课程 | 首页情绪签到 → 3 张推荐卡片 |
| 感官沉浸但不依赖 | 视觉触觉服务专注，不炫技 | 呼吸页只有圆环、阶段文字、主操作 |
| 不制造焦虑 | 断签不警告、不催付费、不弹窗施压 | “今天重新开始也很好”；前 3 次练习无订阅提示 |

### 1.3 目标用户

| 用户 | 核心需求 | 场景 |
|---|---|---|
| 冥想新手 | 明确引导、3–5 分钟短练习 | 通勤、午休、睡前 |
| 焦虑缓解型 | 即时情绪调节、可追踪变化 | 会议前、争吵后 |
| 习惯养成型 | 温和提醒、可见进度 | 晨起、晚间打卡 |
| 深度练习者 | 自定义计时、安静工具 | 静坐、正念行走 |

### 1.4 差异化

不做内容库，做入口：从打开到开始练习最多 3 次点击，没有分类页和搜索。  
不做鼓励，做不评判：去掉引发愧疚的游戏化元素，断签不用红色。  
不做声音依赖，做身体在场：触觉引导为核心，可在静音、不戴耳机、手机放口袋状态完成练习。

## 3. 启动与引导

### 3.1 启动屏

- 纯色背景 `#F5F2ED`，与首页画布完全一致。
- 不加 Logo、文字、动画。
- 通过 Info.plist `UILaunchScreen` + Asset Catalog 颜色实现。
- 启动屏背景色、首屏初始帧背景色、首屏动画起始背景色完全一致。

### 3.2 引导页

仅首次安装，3 页，可跳过：

1. “每天一分钟，心安一下。” + 呼吸曲线意象。
2. 解释提醒用途，再请求通知权限；当前 MVP 暂缓通知，避免额外权限。
3. 情绪偏好初选；可多选、可跳过。

引导页不请求 HealthKit，不请求定位，不强制登录。

## 4. 功能模块

### 4.1 呼吸模块

免费核心留存钩子。

| 功能 | 说明 | 当前状态 |
|---|---|---|
| 引导呼吸 | 圆环随节奏扩张收缩，阶段文字 + 触觉 | ✅ |
| 自由呼吸 | 用户设置吸/呼时长 | ✅ 简化为参数化节奏 |
| 快速镇静 SOS | 1 分钟急性焦虑呼吸 | ✅ |

触觉策略：

- 吸气阶段缓慢增强。
- 呼气阶段缓慢减弱。
- 阶段切换触发 `.soft`。
- 设置可关闭，关闭后动画照常。

### 4.1.1 声音引导策略

声音不是核心依赖，但也不是完全缺席。v0.1 补充“可选声音引导”：

| 能力 | 行为 | 默认 |
|---|---|---|
| 呼吸阶段语音 | 阶段切换时轻声读“吸气 / 屏息 / 呼气” | 开启 |
| 结束语音 | 用户结束或计时完成时读“练习结束” | 开启 |
| 计时开始语音 | 计时器开始时读“开始” | 开启 |
| 一键静音 | 呼吸页 / 计时页右上角直接切换 | 可随时关闭 |

原则：

1. 视觉与触觉仍然完整可用；关闭声音后练习不中断。
2. 语音只做极短提示，不加长引导语。
3. 使用系统 `AVSpeechSynthesizer` 与 `zh-CN` 声音，避免引入第三方依赖。
4. 音频会话使用 `spokenAudio`，并尝试与其他 App 混音，避免突然打断音乐。

### 4.2 引导冥想库

后续分层：

- 免费层：约 45 条精选，3–10 分钟。
- 订阅层：多周课程、睡眠故事、无引导音景。

当前仓库不引入内容库。

### 4.3 触觉与交互式引导

- 触觉引导呼吸：已在呼吸模块。
- 念头放下：后续实现。用户可输入焦虑词，长按让文字随涟漪淡出。
- 触摸身体扫描：探索项。人体轮廓滑动 + 轻触感。

### 4.4 计时器

- 1–60 分钟。
- 环境音混音后续实现。
- 极暗模式界面。

### 4.5 进度与情绪追踪

- 完成 ≥1 分钟即标记。
- 断签不惩罚，文案“今天重新开始也很好”。
- 情绪趋势不结合图形输出因果结论。
- 当前版本显示本周分钟数、35 天热力图、连续天数。
- HealthKit 后续在首次完成练习后请求。

### 4.6 现实声音策略

雨声、流水、虫鸣优先；鸟叫逐条筛选；机械声不引入。后续实现无缝循环与频率均衡。

### 4.7 音频内容来源

后续按三层采购：环境音、引导冥想背景、睡眠故事配乐。订阅核心内容不使用免费素材填充。

## 5. UI 设计

### 5.1 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg-canvas` | `#F5F2ED` | 首页/列表/启动屏 |
| `bg-player` | 主题色柔和渐变 | 引导冥想播放页 |
| `bg-breath` | `#0E0E0F` | 呼吸页 |
| `text-primary` | `#2C2C2E` | 标题/正文 |
| `text-secondary` | `#8E8E93` | 辅助说明 |
| `accent-breath` | `#A8C5D1` | 呼吸环/进度条 |
| `mood-calm→agitated` | `#C5D5CB / #D6D0C4 / #D9C8B4 / #D4B8A8 / #C9A99A` | 情绪五级 |

间距：8pt 基础，页面水平 24pt，卡片内边距 20pt，模块间距 32pt。  
圆角：卡片 16pt，按钮 12pt，呼吸环全圆。  
字体：SF Pro，最高 Medium；大量 Light。  
图标：线性 1.5pt，不用 emoji/卡通。

### 5.2 首页

单屏信息密度极低。

1. 情绪签到条：5 个 44pt 色块，每个色块下显示可读标签（平静 / 还行 / 一般 / 低落 / 焦躁）；下方说明“从左到右：平静 → 焦躁”；选中轻放大；可折叠。
2. 推荐 3 张横滑卡片：名称、时长、一行描述；点击直达播放页。
3. 今日正念分钟数：左侧大数字，右侧连续天数；未练习时显示“今天还没有练习。1 分钟也可以。”

### 5.3 呼吸播放页

- 背景 `#0E0E0F`。
- 中央呼吸圆环：约 180pt，描边 2pt，透明度 0.5–0.8。
- 阶段文字：吸气 / 屏息 / 呼气，透明度 0.5。
- 底部圆形播放/暂停。
- 退出使用半屏确认；已完成时长正常计入。

### 5.4 进度页

- 顶部本周总分钟数。
- 热力图：有练习日按分钟映射透明度；无练习日空心环；当天用小圆点。
- 情绪趋势后续展开；图表说明“数据仅供你自己观察，不下结论。”

### 5.5 空状态

- 首次未签到：签到条居中，底部提示“选一个，或直接开始呼吸”。
- 断签后：“重新开始也很好”。
- 无网络：呼吸/计时器可用，在线内容灰显。

## 6. UI 风格

**一句话**：像清晨还没完全亮起来的房间——看得清轮廓，但没有任何东西在催你。

### 色彩

- 低饱和暖灰打底，雾蓝唯一强调色。
- 不用紫色。
- 强调色只承载功能信息，不装饰。

### 排版

- 最高 Medium，不使用 Bold 及以上。
- 大量 Light + 低透明度辅助文字。
- 留白即内容。

### 形状

- 卡片 16pt，按钮 12pt，无阴影。
- 不用照片、人物插画、卡通形象。
- 扁平但不冰冷。

### 动效

- 慢、少、软。
- 常规过渡 0.3–0.5s，背景呼吸 60s。
- 单屏同时运动元素 ≤2 个。
- 禁止弹跳、庆祝、粒子。

## 7. 商业模式

Freemium。

| 层级 | 内容 |
|---|---|
| 免费 | 呼吸、触觉引导、计时器、基础引导冥想、情绪签到、HealthKit |
| 订阅 | 睡眠故事、多周课程、无限混音、离线下载 |

转化设计：7 天试用、不强迫信用卡；试用结束保留数据；第 10 次练习后解锁限时全库体验；第 3 次练习前不出现订阅提示。

## 7.1 v0.2 / v0.3 实现边界

### v0.2 身体在场

**Core Haptics 同步**

- 呼吸阶段不再使用普通 `UIImpactFeedbackGenerator`。
- 使用 `CHHapticEngine` + `CHHapticAdvancedPatternPlayer` 为吸气、屏息、呼气生成不同触觉模式。
- 吸气：轻、连续、强度渐增。
- 屏息：极弱持续。
- 呼气：较缓、强度渐弱。
- 阶段切换由 `BreathingEngine` 触发，触觉与视觉使用同一状态源。

**HealthKit**

- 用户首次完成练习后请求 HealthKit 写入授权。
- 只写 Mindful Minutes，不读取心率、睡眠、步数或其他健康数据。
- 授权失败或设备不支持时不阻断本地记录。

**Live Activity**

- 呼吸开始时创建锁屏 Live Activity。
- 锁屏显示阶段、剩余时间和圆形进度。
- App 被回收或结束时结束 Activity。
- 系统拒绝、Activity 不可用或无 Widget 渲染时不阻断呼吸。

### v0.3 非声音练习

**念头放下**

- 输入可选，不强制。
- 长按触发 8 秒涟漪淡出。
- 无倒计时压力、无完成率、无引导语。
- 结束后记录一次 `thoughtDistancing` 练习。

**触摸身体扫描**

- 屏幕使用线性人体轮廓。
- 手指经过头颈、胸腹、手臂、腿、足时线条增亮并触发轻触觉。
- 无引导语、无固定节奏。
- 用户自行决定何时结束。

**环境音混音**

- 免费三种：雨声、流水、虫鸣。
- 使用本地生成音景，不依赖第三方音频资源。
- 可分别开关与调音量。
- 预设保存在本机。
- 关闭后呼吸与计时器完整可用。

## 7.2 v0.4 内容基础设施

### 目标

建立可扩展的引导冥想底座，但不把产品变成内容库。免费基础库只保留少量高完成率短练习；播放器优先完成体验，音频资产后续替换。

### 数据 schema

`AtEaseContentManifest`

- `schemaVersion`：v0.7 起为 2。
- `items`：引导冥想条目。
- 每条内容必须包含稳定 `id`、标题、副标题、导师/来源、时长、主题、免费/订阅标记。
- 音频资产分为：`bundled`、`remote`、`generated`；当前 MVP 使用 `scripted` 本地结构化步骤。
- `remoteAudio`：仅 `remote` 内容允许出现；包含 HTTPS URL 与 `fileExtension`。
- 每条步骤包含 `title`、`text`、`durationSeconds`、可选触觉类型。
- 资产台账字段保留：来源、授权类型、授权到期、是否允许 App 内分发、Content ID 状态。

### 本地状态

SwiftData 保存用户态，不保存内容本体：

- `GuidedContentStateModel`
  - `contentID`
  - `isFavorite`
  - `lastPlayedAt`
  - `completedSeconds`
  - `isCompleted`
- 内容本体来自 bundled JSON，便于审阅与版本管理。

### 播放器

- 结构化播放器：按步骤推进，可暂停/继续。
- 阶段切换使用柔和文字淡入，不横滑。
- 结束自动写入 PracticeSession 和 GuidedContentState。
- 提前退出保存已完成分钟数。
- 声音引导尊重设置页开关。
- v0.4 的语音是原型引导，不承诺正式导师音频。

### 免费基础库

v0.4 内置 5 条短练习：

1. 1 分钟微休息。
2. 3 分钟会议前重置。
3. 5 分钟身体着陆。
4. 5 分钟午间放下。
5. 8 分钟睡前整理。

不加入分类页，不加入搜索。练习页只显示“引导冥想”入口。

### 下载底座

- 引入 `ContentDownloadState`：未下载、下载中、已下载、失败。
- 引入下载服务协议，支持后续 remote/bundled asset。
- 当前内置条目不需要下载；UI 隐藏不可用操作。
- 未来 remote item 必须记录授权状态后才允许下载。

## 7.3 v0.5 订阅闭环

### 目标与非目标

目标：

- 用 StoreKit 2 建立免费 / 订阅分层。
- 支持月度与年度自动续期产品、7 天免费试用、恢复购买。
- 订阅状态可缓存，冷启动时可先呈现最近已知状态。
- 订阅入口保持低调：只出现在第 3 次练习后的收尾卡片和设置页。
- 购买、恢复或校验失败时保留本地数据，不阻断呼吸与计时器。

非目标：

- 不做账号系统。
- 不做弹窗施压、限免倒计时、红色促销。
- 不把当前 5 条基础引导冥想改为付费。
- 不在订阅不可用时阻止免费练习。

### 产品分层

| 层级 | 内容 | 状态 |
|---|---|---|
| 免费层 | 呼吸、计时器、念头放下、身体扫描、环境音混音、5 条基础引导冥想、本地进度 | 永远完整可用 |
| 订阅层 | 睡眠故事、多周结构化课程、后续离线下载与深度内容 | 通过 StoreKit 自动续期订阅解锁 |

产品 ID：

| 产品 | ID | 说明 |
|---|---|---|
| 月度订阅 | `com.pocketapps.atease.subscription.monthly` | 自动续期 |
| 年度订阅 | `com.pocketapps.atease.subscription.annual` | 自动续期 |

7 天免费试用由 App Store Connect 的 introductory offer 配置；App 侧展示产品自带的 offer 标签，不自行承诺“未配置也会免费”。

### 订阅状态

App 内只保存最小缓存：

```text
subscriptionState: notSubscribed | subscribed
subscriptionExpiresAt: Date?
cachedAt: Date
lastProductID: String?
```

规则：

1. StoreKit `Transaction.currentEntitlements` 是唯一信任来源。
2. 缓存只用于冷启动展示，启动后立即刷新。
3. 撤销、退款或过期后回到 `notSubscribed`。
4. 缓存读取失败按 `notSubscribed` 处理，但不清除本地练习数据。
5. 无网或 StoreKit 错误保留缓存，界面说明“暂时无法验证”，不反复请求。

### UI 与触发时机

设置页显示：

- 当前状态：免费版 / 订阅中。
- 月度与年度价格由 StoreKit 返回。
- “恢复购买”始终可见。
- 订阅用户显示管理入口提示，但不再重复推销。

练习完成后的收尾卡片：

- 只在完成第 3 次及以后练习出现一行链接：“解锁完整睡眠故事库与多周课程 →”。
- 不弹出全屏订阅页，不使用倒计时或警告色。
- 免费内容可继续使用，点击链接才进入订阅页。

订阅页：

- 列出月度与年度产品。
- 显示 7 天试用说明，仅当 StoreKit 返回 introductory offer。
- 购买与恢复按钮使用普通主按钮样式。
- 错误文案一句话、可重试，不使用警告色。
- 购买成功后返回上一层，不做庆祝动画。

## 7.4 v0.6 订阅内容分发

### 目标与非目标

目标：

- 让订阅状态真正控制引导冥想内容可见性与可播放性。
- 免费层继续展示 5 条基础冥想；订阅层新增 3 条深度练习原型。
- 未订阅用户能看到订阅内容的存在，但不能播放。
- 订阅状态刷新后，内容列表和卡片立即从“锁定”变为“可播放”。
- 订阅过期后自动回到锁定状态，但保留收藏、完成状态和练习记录。
- 不做分类页、搜索、复杂课程管理。

非目标：

- 不把免费 5 条转为付费。
- 不做课程签到、断课提醒、倒计时或追更提示。
- 不在播放器内重复弹出订阅页。
- 不承诺正式导师音频；本版仍是结构化文本 + 中文语音原型。

### 内容分层

| 层级 | 内容 | 数量 |
|---|---|---|
| 免费层 | 基础呼吸、短冥想、会议重置、身体着陆、睡前整理 | 5 条 |
| 订阅层 | 压力释放课程第一课、深度身体扫描、睡前故事原型 | 3 条 |

订阅层内容 ID：

1. `stress-release-course-day-1`
2. `deep-body-scan-1080`
3. `sleep-story-lighthouse-900`

这些条目继续复用 `MeditationContentItem.isSubscriptionRequired = true`，避免在 v0.6 引入第二套内容模型。

### 访问规则

`MeditationContentAccessService` 是唯一访问判定入口：

```text
canPlay(item):
  if !item.isSubscriptionRequired: return true
  return isSubscribed
```

列表规则：

1. “全部”显示免费条目在前，订阅条目在后；免费条目按 manifest 原序，订阅条目按 manifest 原序。
2. “收藏”显示用户收藏过的条目，包括锁定订阅条目；锁定卡片不隐藏收藏入口。
3. 未订阅时订阅卡片显示 `lock` 与“订阅解锁”，但不显示红色、角标或倒计时。
4. 已订阅时订阅卡片与免费卡片使用同一播放入口。

播放器规则：

1. UI 只应把可播放条目传给播放器。
2. 播放器仍做二次判定；未授权时不启动播放器，也不保存练习记录。
3. 二次失败显示“需要订阅解锁”，不做反复弹窗。

### 状态联动

`AtEaseRootView` 持有唯一的 `AtEaseSubscriptionService`，并注入 environment：

```text
App 启动 → 加载缓存 → refresh entitlement → 更新列表
购买成功 → service state = subscribed → 列表自动解锁
恢复成功 → 同上
订阅过期 / 撤销 → refresh 后回到锁定状态
```

设置页、订阅页、练习页共用同一 service，避免出现两个状态源。

### 验收

- 未订阅：免费 5 条可播放，订阅 3 条显示锁定，不触发播放。
- 已订阅：8 条都可播放。
- 收藏订阅条目后，未订阅仍在“收藏”中显示锁定卡片。
- 订阅刷新成功后列表自动解锁。
- 订阅过期后列表自动锁定，历史记录不删除。
- 播放器二次判定未授权时不产生 PracticeSession。

## 7.5 v0.7 远程音频与离线播放

### 目标与非目标

目标：

- 将内容 schema 升级到 v2，为远程音频提供稳定描述。
- 支持 `remote` 音频在首次播放前下载到 App 沙盒。
- 同一条内容下载成功后，后续播放不再请求网络。
- 下载中、成功、失败都有清晰状态。
- 播放器仍先做订阅访问校验，再准备音频。
- 音频失败不产生练习记录，也不阻断免费结构化练习。

非目标：

- 不做后台批量预下载。
- 不做手动管理页和存储清理页。
- 不做断点续传。
- 不做 CDN 签名刷新。
- 不在本版接入真实付费音频资产；当前 8 条内置内容仍为结构化原型。

### 远程音频 schema

```json
{
  "audioKind": "remote",
  "remoteAudio": {
    "url": "https://example.com/audio.m4a",
    "fileExtension": "m4a"
  }
}
```

校验规则：

1. `remote` 内容必须包含 `remoteAudio`。
2. `scripted` / `bundled` 不允许带 `remoteAudio`。
3. 远程 URL 必须是 HTTPS。
4. 文件扩展名只允许 `m4a`、`mp3`、`wav`、`aac`。
5. schema v2 保留现有步骤时长校验。

### 下载与播放流程

```text
点击开始
  → 订阅访问校验
  → 判断 audioKind
      scripted / bundled: 立即启动结构化播放
      remote:
        → 检查本地 audio.<ext>
          存在：使用本地文件播放
          不存在：进入 downloading → 下载 HTTPS 文件 → 移入沙盒 → 播放
  → 下载成功后标记 downloaded
  → 下载失败显示“音频暂时无法准备”，不写练习记录
```

本地路径：

```text
Documents/Downloads/<contentID>/audio.<fileExtension>
```

### 状态规则

| 状态 | 含义 |
|---|---|
| `notApplicable` | scripted / bundled，无需下载 |
| `notDownloaded` | remote 内容尚未下载 |
| `downloading` | 正在获取远程音频 |
| `downloaded` | 本地文件已存在 |
| `failed` | 网络或文件移动失败 |

UI 状态：

1. `downloading` 显示“正在准备音频”。
2. `failed` 显示“音频暂时无法准备”。
3. 不使用警告色；按钮保持可用，可重试。
4. 下载中隐藏播放按钮，避免同时触发多次。

### 技术边界

- `MeditationAudioPreparationService` 是唯一远程音频准备入口。
- `ContentDownloadService` 仍负责文件下载与本地路径管理。
- 播放服务协议便于替换 AVAudioPlayer / AVAudioEngine，并允许测试注入 mock。
- schema v2 的 `remoteAudio` 可为空；正式音频资产上架前 UI 不显示下载入口。

## 7.6 v0.8 音频下载管理

### 目标与非目标

目标：

- 让用户看到哪些远程音频已下载、总缓存大小，并可以删除或重新下载。
- 设置页新增“离线音频”入口。
- 管理页只处理 `audioKind == remote` 的内容，不展示 scripted / bundled。
- 删除音频只删除沙盒中的 `Downloads/<contentID>/`，不删除练习记录、收藏或完成状态。
- “清理全部”一次删除所有远程音频缓存。
- 下载和删除操作状态清晰、可重复触发，无警告色。
- 订阅过期后，已下载内容保留；再次播放仍需通过访问校验。

非目标：

- 不做后台批量预下载。
- 不做单个内容进度条。
- 不做自动清理。
- 不做存储配额设置。
- 不把 scripted / bundled 内容移入下载管理。

### 信息模型

`AudioDownloadSummary`

```text
contentID
title
subtitle
fileExtension
fileURL
fileSizeBytes
modifiedAt
isSubscriptionRequired
```

`AudioDownloadItemState`

```text
idle | downloading | downloaded | failed
```

`MeditationAudioDownloadManager` 负责：

1. 加载 bundled manifest。
2. 过滤 remote 内容。
3. 检查本地文件并计算大小。
4. 提供 `download`、`remove`、`removeAll`、`reload`。
5. 管理页操作后自动刷新。

文件层新增能力：

```text
downloadedAudioURLs()
fileSize(at:)
removeDownload(contentID:)
removeAllDownloads()
```

### UI

设置页：

```text
内容
├── 订阅
└── 离线音频
```

离线音频页：

- 顶部显示“已缓存 X 条 / Y MB”。
- 每条 remote 内容显示标题、副标题、状态和操作。
- 未下载：显示“下载”。
- 下载中：显示 `ProgressView`。
- 已下载：显示大小和“删除”。
- 失败：显示“重试”。
- 页面右上角提供“清理全部”，只有存在缓存时可用。
- 无 remote 内容时显示“还没有远程音频内容。”，不显示催促文案。

订阅锁定规则：

1. 未订阅的订阅内容只显示“订阅解锁”，不提供下载。
2. 已订阅内容显示“下载”。
3. 免费远程内容也支持下载。
4. 删除已下载内容不受订阅状态影响。

### 技术边界

- `ContentDownloadService` 继续负责文件系统与下载。
- `MeditationAudioDownloadManager` 是管理页唯一状态源。
- `MeditationAudioPreparationService` 继续负责播放前准备。
- 缓存目录不存在时视为空，不主动创建。
- 删除失败使用中性提示“暂时无法删除”，不阻断重试。

### 验收

- 设置页可以进入离线音频管理页。
- 当前 catalog 没有 remote 内容时显示空状态。
- mock remote 内容下载后显示大小和删除操作。
- 删除单条内容后文件目录消失，记录保留。
- 清理全部后缓存总数归零。
- 订阅过期后已缓存文件仍可见、可删除。

## 7.7 v0.9 可选预下载与缓存状态联动

### 目标与非目标

目标：

- 将音频缓存状态提升为 App 级共享状态。
- 练习列表、播放器和离线音频管理页使用同一个 `MeditationAudioDownloadManager`。
- remote 内容在练习列表中显示“已离线 / 下载中”状态。
- 用户从播放器离开后，缓存状态自动刷新。
- 提供可选“自动预下载”，默认关闭。
- 开启后按顺序预下载当前可访问的 remote 音频，不并发请求。
- 失败内容保持可重试状态，后续条目继续处理。
- 预下载可取消。

非目标：

- 不使用 BGTaskScheduler 做 OS 级后台任务。
- 不默认自动下载，避免消耗流量和存储。
- 不下载用户当前无权限的订阅内容。
- 不做并发队列和下载优先级。
- 不做断点续传。
- 不在预下载时弹窗。

### 共享状态

`AtEaseRootView` 持有唯一：

```text
AtEaseSubscriptionService
MeditationAudioDownloadManager
```

分发方式：

```text
.environmentObject(subscription)
.environmentObject(audioDownloadManager)
```

作用范围：

1. 练习页：显示已离线 / 下载中。
2. 播放器关闭后：刷新缓存状态。
3. 设置页：开关预下载。
4. 离线音频页：下载、删除、清理。

### 预下载规则

设置项：

```text
atease.autoPredownloadEnabled
```

默认值：

```text
false
```

触发时机：

1. 用户开启设置开关。
2. Root 启动或订阅状态变化时，若开关已开启。

候选内容：

```text
audioKind == remote
  && !isDownloaded
  && (!isSubscriptionRequired || isSubscribed)
```

处理顺序：

1. 按 manifest 原序。
2. 逐条下载。
3. 单条失败记录 failed，然后处理下一条。
4. 全部处理完成后刷新统计。
5. 用户可取消；取消后不再开始新条目。

进度状态：

```text
isPredownloadRunning
predownloadCompletedCount
predownloadTotalCount
predownloadCurrentID
```

设置页显示：

- 开关关闭：“自动预下载”。
- 开关开启并运行：“正在预下载 X / Y”。
- 开关开启但无候选：“自动预下载新内容”。
- 运行中显示“取消”。

### 列表与播放器联动

练习列表：

1. remote 内容已下载显示“已离线”。
2. remote 内容正在下载显示“下载中”。
3. scripted / bundled 不显示下载状态。
4. 已离线状态不使用强调色做营销。

播放器：

1. 播放前仍由 `MeditationAudioPreparationService` 处理。
2. 播放器下载完成后，关闭页面刷新共享缓存。
3. 管理页删除后，列表状态自动回到未下载。

### 验收

- 默认状态不自动下载。
- 开启开关后按顺序处理可访问 remote 内容。
- 未订阅时跳过订阅内容。
- 已下载内容跳过。
- 单条失败后继续后续内容。
- 取消后不开始新下载。
- 播放器内下载并退出后，列表显示已离线。
- 设置页、离线音频页、练习列表状态一致。
