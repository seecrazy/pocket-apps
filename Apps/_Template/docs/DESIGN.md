# Template App 设计文档

> 状态：模板  
> 更新时间：2026-11-14

## 目标

- 提供最小可构建的 SwiftUI App 骨架。
- 展示新增 App 必须维护的文档、资源与测试位置。

## 模板内容

- `Project.swift`
- `Sources/App.swift`
- `Tests/TemplateAppTests.swift`
- `Resources/Assets.xcassets`
- `Resources/PrivacyInfo.xcprivacy`
- 本 README 与 docs/

## 新增 App 清单

1. 复制目录。
2. 修改 `Project.swift`。
3. 在 `Workspace.swift` 注册。
4. 修改 App 名称和 Bundle ID。
5. 更新图标与隐私清单。
6. 编写真实的设计与进度文档。
