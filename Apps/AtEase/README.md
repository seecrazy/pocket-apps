## 产品定位

**让“打开 App”这件事本身不构成压力。**  
呼吸与计时器完全免费，承担日常习惯建立；深度睡眠故事与结构化课程属于后续订阅方向。

## 设计原则

| 原则 | 含义 | 当前落地 |
|---|---|---|
| 零摩擦启动 | 无登录、无注册、无搜索 | 首页可直接签到、下滑/点击开始呼吸 |
| 情绪优先 | 从当下情绪进入，不做内容库 | 情绪签到映射 3 张推荐卡片 |
| 身体在场 | 视觉 + 触觉辅助，不依赖声音 | 呼吸圆环、阶段文字、系统触觉 |
| 不制造焦虑 | 不断签惩罚、不弹窗施压 | 文案“今天重新开始也很好” |
| 克制视觉 | 纯色、留白、慢动效 | 暖灰画布、雾蓝强调、无 Bold 字重 |

## 快速开始

在仓库根目录执行：

```bash
./scripts/generate.sh
open PocketApps.xcworkspace
```

选择 `AtEase` scheme，在模拟器或真机运行。

## 当前能力

- 一次性 3 页引导页，可跳过。
- 首页情绪签到：5 级抽象色块，可跳过。
- 基于情绪的 3 张推荐卡片。
- 引导呼吸：
  - 4-7-8
  - Box Breathing
  - 1 分钟 SOS
- 呼吸视觉：近纯黑背景、圆环扩张收缩、阶段文字。
- 触觉辅助：阶段切换轻触感；设置可关闭。
- 自由计时器：1–60 分钟。
- 本地 SwiftData 记录：情绪签到、练习分钟数。
- 进度页：本周分钟数、近 35 天热力图、连续天数。
- 设置：触觉开关、首页默认时长、订阅状态占位。

## 体验架构

```text
App 启动
├── 引导页（仅首次，3 页可跳过）
└── 主界面
    ├── 今日
    │   ├── 情绪签到
    │   ├── 推荐卡片
    │   └── 今日分钟数
    ├── 练习
    │   ├── 呼吸
    │   ├── 计时器
    │   └── 后续：引导冥想 / 触觉引导
    ├── 进度
    │   ├── 本周分钟数
    │   ├── 日历热力图
    │   └── 连续天数
    └── 设置
```

## 数据与隐私

当前版本：

| 数据 | 存储 | 是否上传 |
|---|---|---|
| 情绪签到 | SwiftData / App 沙盒 | 否 |
| 练习记录 | SwiftData / App 沙盒 | 否 |
| 设置偏好 | UserDefaults | 否 |

当前版本不接入账号、云端、广告、第三方统计。HealthKit 与后台音频属于后续路线，接入前会在设计文档中补充权限时机。

## 声音引导

v0.1.1 已加入可选声音引导：

- 呼吸阶段切换时轻声提示“吸气 / 屏息 / 呼气”。
- 计时器开始与结束时提示“开始 / 练习结束”。
- 呼吸页和计时页右上角可一键静音。
- 设置页提供声音引导开关。
- 关闭声音后，视觉圆环与触觉反馈仍然完整可用。

声音引导使用系统中文语音，不依赖第三方音频资源，也不会上传任何数据。
